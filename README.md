# 模拟炒股训练场

这是一个 A 股 + 美股模拟炒股 PWA 网页。它可以本地运行，也可以部署到云端。行情会优先尝试读取 Yahoo Finance；如果网络或接口不可用，会自动使用仿真行情，保证你可以继续练习交易、持仓和复盘。

## 云端版本

想让手机和电脑在任何地方都能打开，需要部署到云端。部署说明看：

```text
DEPLOY.md
```

云端部署时请设置：

```text
APP_PASSWORD=你的访问密码
DATA_DIR=/var/data
SESSION_SECRET=一串随机长字符
```

设置 `APP_PASSWORD` 后，新用户注册时需要把它作为邀请码。注册后每个用户名都有独立的模拟账户、现金、持仓、自选和复盘。

Render 免费版请使用项目里的默认 `render.yaml`，它不会配置持久磁盘；长期使用再升级持久存储。

## 启动

最简单方式：双击这个文件：

```text
启动模拟炒股.command
```

它会自动启动服务，并打开电脑浏览器。

如果你想手动启动，也可以在这个文件夹里运行：

```bash
node server.js
```

然后打开浏览器：

```text
http://localhost:4173
```

## 手机怎么打开

1. 电脑先双击 `启动模拟炒股.command`。
2. 手机和电脑连同一个 Wi-Fi。
3. 终端窗口会显示类似这样的手机地址：

```text
http://192.168.1.23:4173
```

4. 在手机浏览器输入这个地址。

如果 Mac 弹出防火墙提示，请选择允许。不要在公共 Wi-Fi 下长期打开这个服务。

## 怎么用

1. 先看“自选”页，观察 A 股 ETF、A 股个股和美股的涨跌。
2. 到“交易”页选择股票，输入数量和下单理由，再提交模拟订单。
3. 到“持仓”页看现金、持仓、市值和浮盈亏。
4. A 股买入后默认不能当天卖出；需要练习第二天卖出时，点“模拟到下一交易日”。
5. 到“复盘”页记录为什么买、为什么卖、哪里判断错了。

## 当前规则

- 初始人民币现金：100,000 元。
- 初始美元现金：10,000 美元。
- A 股：100 股一手，模拟 T+1，模拟涨跌停、佣金、印花税、过户费。
- 美股：1 股起买，模拟基础手续费。
- 免费行情可能延迟或不可用；这个项目是学习工具，不构成投资建议。

## 数据保存

账户、订单和复盘会保存在：

```text
data/state.json
```

如果想重新开始，可以删除这个文件，或者以后我可以给你加一个页面里的“重置账户”按钮。
